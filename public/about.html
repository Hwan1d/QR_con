🔄 4단계 작동 프로세스

1

호스트 방 생성 & QR 렌더링

PC에서 index.html이 열리면 고유 ID(qrcon-xxxxx)로 PeerJS 노드를 열고, 해당 주소가 담긴 QR 코드를 브라우저에서 즉시 생성합니다.

2

QR 스캔 & P2P 핸드셰이크

스마트폰으로 QR을 찍으면 ?peer=ID 파라미터를 읽어 PC 브라우저와 1:1 WebRTC 데이터 채널을 연결하고 join-controller 트리거를 발사합니다.

3

스테이지 언락 & 컬러 배정

PC가 첫 입장 신호를 받는 순간 QR 화면이 폭발하듯 사라지며 스테이지가 열립니다. 동시에 각 스마트폰에 고유 색상(민트·핑크·옐로우 등)을 역전송합니다.

4

독립 커서 & 협동 아케이드

접속한 각 유저는 players Map에 독립 객체로 등록되어 각자의 커서, 닉네임 태그, 벽돌깨기 패들을 동시에 끊김 없이 조종합니다.

🛠️ 핵심 기술 포인트

🌐 1. 왜 다른 네트워크(LTE/5G)에서도 될까?

로컬 IP(192.168.x.x) 방식은 같은 공유기 안에서만 작동하지만, 본 프로젝트는 WebRTC STUN/ICE 홀펀칭과 PeerJS 시그널링을 통해 외부 모바일 네트워크에서도 PC 브라우저와 직접 연결됩니다. 

const peer = new Peer(roomId);
peer.on('connection', (conn) => {
  conn.on('data', (msg) => handleAction(msg));
});

👥 2. 멀티플레이어 독립 상태 관리

여러 명이 동시에 들어와도 서로의 커서가 섞이지 않도록 기기별 고유 playerId를 키로 하는 Map 구조에서 개별 좌표(x, y, vx, vy, paddleX)를 관리합니다. 

const players = new Map();
// playerId -> { x, y, vx, vy, color, paddleX, trail }

🛡️ 3. 카메라 미리보기( 유령 접속 ) 방지

스마트폰 기본 카메라로 QR을 비출 때 백그라운드에서 URL을 미리 열어보는(Pre-render) 현상을 막기 위해, 실제 화면이 활성화(visibilityState === 'visible')된 순간에만 연결을 수립합니다. 

if (document.visibilityState === 'visible') {
  startConnection();
}
